# Разведка поставщиков и партнёров по всем направлениям (15.09.2026)

Задача: для каждого из 44 направлений ПРОМКОНТУРА найти у кого выгоднее стать дилером/партнёром,
собрать публичные цены на эталонные позиции, дать приоритет и шаблоны обращения.

1. Снять витрину: направления, бренды, наши цены (tools/data/*.json).
2. 7 агентов-разведчиков параллельно (Exa + WebFetch; Firecrawl без кредитов):
   насосы (глубоко) · привод/электрика/КИПиА · трубопровод/вода · воздух/климат ·
   механика/запчасти · производство/обработка · логистика/упаковка/пищевые/безопасность.
3. По каждому: производители, дистрибьюторы, оптовики РФ; условия дилерства/партнёрки; цены.
4. Сводная матрица «кто дешевле / с кого начать».
5. Шаблоны писем-запросов (отправка только с согласия Александра).
6. Отчёт docs/reports/2026-09-15-razvedka-partnerov.md, сырьё — docs/research/partners/.
