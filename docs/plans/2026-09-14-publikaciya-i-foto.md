# План: публикация макета ПРОМКОНТУР и генерация фото (14.09.2026)

1. Найти в макете все места под фото (плейсхолдеры `.ph`).
2. Сгенерировать фото (22 кадра) — `tools/gen_photos.py`.
3. Сжать и вставить в макет — `tools/place_photos.py`.
4. Проверить в браузере (главная, каталог, товар, блог).
5. Публичный репозиторий GitHub + Pages из `project/`.
6. Отчёт в `docs/reports/`.
