# Бэкенд для ПРОМКОНТУРА: варианты (15.09.2026)

Сейчас кабинеты закупщика и поставщика и панель оператора — рабочий фронтенд без сервера: данные в localStorage
браузера, у каждого посетителя свои. Для настоящей работы нужны база, API и авторизация.

## Ограничение, которое решает выбор
**152-ФЗ:** персональные данные граждан РФ (ФИО, телефоны, почты закупщиков и сотрудников) должны храниться на серверах в России.
Поэтому зарубежные облака (Supabase, Firebase, Vercel) для боевой базы не подходят — только для прототипа на тестовых данных.

## Варианты

| | A. Свой сервер в РФ | B. Российское облако (managed) | C. Готовая B2B-платформа |
|---|---|---|---|
| Что это | Node.js (Fastify) + PostgreSQL на VPS/выделенном сервере | То же, но БД и хранилище — управляемые сервисы Yandex Cloud / Selectel | 1С-Битрикс «B2B-кабинет» / аналог |
| Где | уже есть сервер SmartApe или Timeweb/Beget VPS | Yandex Cloud, Selectel, VK Cloud | хостинг Битрикса |
| Плюсы | дёшево, полный контроль, текущий фронт сохраняется | бэкапы, масштаб, меньше админства | много «из коробки», 1С-обмен |
| Минусы | бэкапы и безопасность на нас | дороже (≈ 8–20 тыс ₽/мес на старте) | чужой интерфейс, дизайн и логику переделывать, лицензия |
| Фронт | текущий статический сайт + API | то же | переносить в шаблоны платформы |

**Рекомендация — A или B:** фронт остаётся (витрина на статике, кабинеты уже написаны), добавляется API.
A — если хотим минимальных расходов и сервер SmartApe свободен; B — если важны бэкапы и отказоустойчивость без своего админа.

## Что входит в MVP (≈ 3–4 недели)
1. **Авторизация:** вход по телефону (код в MAX-боте или SMS через SMS.ru), роли закупщик / согласующий / поставщик / оператор, сессии.
2. **Каталог в базе:** импорт фидов поставщиков (XML/YML/CSV/API) по расписанию, цены с правилами наценки, остатки, поиск.
3. **Заказы и КП:** корзина → счёт (PDF), статусы заказа, запросы КП с ответом инженера, документы.
4. **Кабинет закупщика:** заказы, согласование по маршруту с лимитами, регулярные закупки (планировщик), сотрудники, реквизиты.
5. **Кабинет поставщика:** заявки и статусы, редактор прайса, журнал обменов, расчёты.
6. **Панель оператора:** CRM-канбан, очередь «ждёт человека», правила наценки, права, журнал изменений.
7. **Уведомления:** почта + MAX-бот.

## Интеграции (после MVP)
amoCRM или своя CRM (сейчас в макете своя), 1С (выгрузка заказов и документов), ЭДО (Диадок / СБИС), банк (выписки, счета),
проверка контрагента по ИНН (DaData / Контур.Фокус), перевозчики (ПЭК, Деловые Линии, СДЭК — расчёт и треки), телефония.

## Модель данных (основа)
companies, users, roles, sessions · suppliers, feeds, feed_runs, price_items · products, categories, brands · price_rules ·
carts, orders, order_items, order_events, documents · quotes · approvals, approval_steps · regular_purchases ·
deals (CRM), deal_events · audit_log · notifications.

## Что нужно решить
1. Где размещаем: SmartApe / VPS в РФ / Yandex Cloud / Selectel.
2. CRM: своя (как в макете) или amoCRM.
3. Вход: код в MAX-боте или SMS (нужен аккаунт SMS.ru и бюджет).
4. Домен для сайта и API.
