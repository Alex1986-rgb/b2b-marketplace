# План: кабинеты, админка и доводка сайта (14.09.2026, этап 3)

Сайт статический (GitHub Pages) — всё работает в браузере, состояние в localStorage, режим «демо» честно подписан.

1. **Вход и сессия** — `tools/site/auth.js`: вход по телефону и коду (демо-код на экране), роли закупщик/поставщик/оператор,
   меню пользователя в шапке, выход, защита закрытых разделов (редирект на /vhod/).
2. **Кабинет закупщика** — `tools/gen_cabinet.js` + `tools/site/cabinet.js` + `tools/data/cabinet.json`:
   разделы бокового меню отдельными страницами (заказы, согласование, регулярные закупки, запросы КП, счета и УПД,
   спецификации, сотрудники, реквизиты), рабочие действия с сохранением.
3. **Кабинет поставщика** — `tools/gen_vendor.js` + `tools/site/vendor.js` + `tools/data/vendor.json`:
   заявки, редактор прайса (цена/остаток/срок, пакетно), выгрузка и синхронизация, расчёты, настройки.
4. **Админка оператора** — `tools/gen_admin.js` + `tools/site/admin.js` + `tools/data/admin.json`:
   меню панели, правила наценки CRUD, фиды, CRM-канбан с перетаскиванием, очередь автопилота, права, модерация отзывов, журнал.
5. **Сборщик** — контракт генераторов `tools/gen_*.js`, каркасы шапок (витрина / кабинет поставщика / панель оператора),
   подключение скриптов по разделам, привязка пунктов меню экранов макета к новым страницам.
6. **Проверка и выкладка** — обход ссылок, check_site 1440/390, сценарии кабинетов в браузере, отчёт.

## Контракт генератора страниц
`module.exports = ctx => [{ path, title, desc, h1, html, chrome: 'store'|'ops'|'vendor', scripts: ['cabinet.js'], index: false }]`
`ctx = { BASE, esc, rub, cut, load(file), crumbs(items), img(id,h,fit,extra,alt), ROUTES, products, faqBlock }`.
HTML — содержимое `<main id="main">…</main>`; шапка/подвал подставляются сборщиком по `chrome`.
