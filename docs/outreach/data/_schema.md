# Схема JSON для инструкции по партнёрству

Файл — массив направлений:
[{
  "slug": "nasosy", "name": "Насосы", "cluster": "Перекачка, трубопровод, вода",
  "strategy": "дилер | агент (комиссия за заявку) | дистрибьютор с фидом | Китай под заказ | свой бренд ZR",
  "summary": "1–2 фразы: как закрываем направление и почему так",
  "coverage": ["какие подкатегории витрины закрывает каждый партнёр — перечислить все подкатегории направления"],
  "partners": [{
    "priority": 1,                       // 1 — писать в первую неделю, 2 — после первых ответов, 3 — резерв
    "company": "ООО «СиэНПи Рус» (CNP/Aikon)",
    "role": "производитель | офиц. дистрибьютор | дилерская сеть | ВЭД-агент | площадка",
    "covers": ["подкатегории витрины, которые закрывает"],
    "brands": ["CNP", "Aikon"],
    "known": "что известно об условиях (скидка, порог, отсрочка, склад, фид/API) — только из источников",
    "channel": { "how": "форма «Стать дилером» | e-mail | телефон | личный кабинет",
                 "url": "страница для дилеров/контактов", "email": "публичный e-mail отдела продаж или null",
                 "phone": "публичный телефон или null", "who": "кому адресовать: отдел дилерских продаж / региональный менеджер" },
    "template": "dealer | agent | feed | quote | oem | ved | marketplace",
    "hook": "1–2 предложения персонализации письма именно для этой компании",
    "ask": ["конкретные вопросы/документы, которые запросить именно у них"],
    "attach": ["что приложить: карточка компании, пример выгрузки, объём спроса"],
    "expect": "чего ждать: срок ответа, типичные условия, возможные требования",
    "leverage": "аргумент для торга (конкуренты-дилеры, у ЭТМ есть API и т.п.) или null",
    "risks": "риски/что проверить (санкции, контрафакт, путаница омонимов) или null",
    "source": "файл/URL источника"
  }],
  "gaps": "чего не хватает и как добрать"
}]

Правила: не выдумывать контакты — только публичные с официальных сайтов, иначе null и "how": "форма на сайте" с url.
Каждая подкатегория направления должна попасть хотя бы в один partners[].covers. 3–6 партнёров на направление.
