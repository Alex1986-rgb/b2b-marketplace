## Что сделано
- **135 страниц** вместо одного файла-макета: 35 экранов витрины, кабинетов и панели оператора + сгенерированные из данных
  24 товара, 15 статей, 44 направления, 15 производителей; служебные — контакты, карта сайта, политика, условия, 404.
- **Каждая карточка открывает свою страницу** (товары, статьи, направления, бренды). Проверено обходчиком `tools/qa/crawl_links.js`:
  битых ссылок 0, клик-тесты каталога/блога/направлений на 390 и 1440 — OK.
- **Вид настоящего сайта**: слой `tools/site/skin.css` (карточки с тенью и скруглением, пилюли, чат-пузыри, степпер заказа,
  прилипающая шапка), шрифты Fira Sans с кириллицей, 138 иконок (Lucide + 16 своих), знак и фавиконы,
  знаки брендов в бегущей строке (без копирования чужих логотипов).
- **Фото**: 45 кадров (сцены с синей тонировкой, товары на белом), WebP + ленивая подгрузка; страницы легче в 2–2,4 раза.
- **Интерактив без бэкенда** (`tools/site/site.js`): корзина с пересчётом и НДС 22 %, фильтры и сортировка каталога,
  формы с проверкой и экраном «принято (демо)», мобильное меню, карусели, поиск.
- **Телефон**: шапка ~150 px, цена товара сразу после фото, таблицы-карточки, фильтры, кабинет-лента.
- **SEO**: title/description всех публичных страниц, canonical, OG, JSON-LD (Organization, BreadcrumbList, Product, Article, FAQPage),
  sitemap (118 адресов), robots, noindex у кабинетов и панели.
- **Доступность**: контраст (акцент #4a6f94), «К содержимому», подписи полей и кнопок-иконок, клавиатурный степпер, пауза бегущей строки.
- **Контент и данные**: ~400 правок цифр и текстов по ТЗ владельца (`docs/spec-screens.md`), убраны юр. риски
  («официальные поставки»), наценка и закупочные цены убраны с главной.

## Как пересобрать
```
node tools/build_site.js        # сборка site/ (~1 мин, атомарная)
node tools/check_site.js        # ссылки, мета, консоль, переполнение 1440/390
node tools/qa/crawl_links.js    # каждая карточка → своя страница
git push                         # GitHub Pages публикует site/ (workflow pages.yml)
```
Данные новых страниц — `tools/data/*.json`, шаблоны — `tools/gen_pages.js`, экраны — `project/*.dc.html`.

## Что осталось
- Отзывы и рейтинг есть только у Grundfos CR 32-4 (без реальных данных не добавляем).
- Подкатегории направлений (кроме «Насосов») ведут в чат с запросом — отдельных каталогов по ним нет.
- Кабинеты и панель работают без сервера: данные в localStorage браузера; для реальной работы нужен бэкенд (API, авторизация, БД).
- Ложное срабатывание обходчика: подкатегории «Насосов» ведут в каталог с `?tip=` — скрипт отбрасывает параметр.
