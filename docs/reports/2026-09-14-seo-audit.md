## Что поправить в `build_site.js` (не моя зона — готовые фрагменты)

**1. «Контакты» в подвале → новая страница** (строка с `byText`):
```js
const byText = { 'Политика конфиденциальности': 'politika-konfidencialnosti/', 'Условия использования': 'usloviya-ispolzovaniya/', 'Карта сайта': 'karta-sajta/', 'Весь каталог': 'napravleniya/', 'Блог': 'blog/', 'Контакты': 'kontakty/' };
```
Сейчас кнопка «Контакты» размечена в макете переходом на экран `about` (`data-go`), поэтому byText её не
ловит — добавить после цикла по `[data-go]`:
```js
for (const a of c.querySelectorAll('footer a')) if (a.textContent.trim() === 'Контакты') a.setAttribute('href', base + 'kontakty/');
```

**2. Хлебные крошки: `item` у каждого звена кроме последнего.** В `inPage` собирать ссылки звеньев:
```js
return row ? [...row.children].filter(x => x.textContent.trim() && x.textContent.trim() !== '/')
  .map(x => ({ name: x.textContent.trim(), href: x.getAttribute('href') || (x.querySelector('a') || {}).getAttribute?.('href') || x.getAttribute('data-href') || '' })) : [];
```
и в `jsonLd`:
```js
if (snap.crumbs.length > 1) {
  const last = snap.crumbs.length - 1;
  out.push({ '@context': 'https://schema.org', '@type': 'BreadcrumbList', itemListElement: snap.crumbs.map((c, i) => {
    const it = { '@type': 'ListItem', position: i + 1, name: c.name };
    if (i === 0) it.item = url('');
    else if (i === last) it.item = url(r.path);
    else if (c.href) it.item = ORIGIN + c.href;   // href уже с BASE
    return it;
  }) });
}
```
Если у среднего звена ссылки нет — лучше сделать его ссылкой в макете (Насосы → `katalog/nasosy/`,
Grundfos → `proizvoditeli/grundfos/`, Компрессоры → `napravleniya/`), иначе звено из разметки убрать.

**3. Product — дополнить поля:**

if (id === 'product') out.push({ '@context': 'https://schema.org', '@type': 'Product',

## Что осталось / что нужно от владельца

- **Домен.** Сейчас всё на `alex1986-rgb.github.io/b2b-marketplace/` — поддомен GitHub, в Яндексе такие
  сайты ранжируются плохо, и canonical/sitemap придётся перевыпустить. Купить домен, собрать с
  `ORIGIN=https://домен BASE=/`, добавить CNAME.
- **Яндекс Вебмастер и Google Search Console** — подтвердить права (метатег или файл в `tools/site/static/`),
  отправить sitemap, в Вебмастере указать регион и заполнить «Сведения о сайте».
- **Реквизиты юрлица, телефон, адрес** — для страницы «Контакты», Organization/contactPoint и доверия
  Яндекса к коммерческому сайту (без них коммерческие факторы проседают). Настоящие почты вместо
  `*.example`.
- **Яндекс Метрика** — счётчика нет.
- **Контент:** один товар, одна статья, один бренд — для выдачи это витрина, а не каталог. Реальный
  трафик начнётся с программной генерации карточек/брендов/направлений из фидов.
- Не проверено: браузерная проверка `check_site.js` без `--no-browser` (переполнение/консоль) не запускалась.
