# Аудит «макетности» сайта ПРОМКОНТУР — 14.09.2026

Что сделано: обойдены все 42 страницы (`find site -name index.html`, включая `kontakty/`) на ширине 1440 и 390 px
(puppeteer-core, Chrome), просмотрены скриншоты, скриптом в браузере искались пустые коробки 8–120 px,
пустые крупные плашки, штриховки, служебные подписи. Обход сделан на сборке после подключения фото и иконок
(логотип-знак, иконки `.ico .i-*`, миниатюры в таблицах уже на месте — это в отчёт не входит).
Ничего в коде не правилось. Примеры — в `docs/reports/img-maketnost/`.

Итог автоматики: пустых квадратов-заглушек больше нет (осталось 0 на витрине), штриховок нет.
Всё найденное ниже — это уже не «дырки», а приёмы, по которым сайт всё ещё читается как макет:
плоские серые плиты без скругления вне `.blueprint`, прямоугольные «пузыри», квадратные счётчики,
packshot на серой подложке другого тона, служебные страницы-спецификации в открытом доступе,
а на телефоне — таблицы и фильтры, свёрстанные как десктоп.

Приоритеты: **P1** — видно сразу, выдаёт макет/ломает сценарий; **P2** — заметно при просмотре; **P3** — полировка.

## 4. Общие правила для `tools/site/skin.css`

1. **`.row-hover` без скругления.** Сейчас `border-radius:8px` + inline `border-top` = кривые концы линий по всему сайту
   (типовые задачи, списки документов). Поставить `border-radius:0`, ховер — фоном, линию оставить прямой.
2. **Карточки с цветной полосой слева/сверху.** `.blueprint[style*="border-left: 3px"]`, `[style*="border-top: 3px"]` →
   заменить полосу на `box-shadow: inset 3px 0 0 …` / `inset 0 3px 0 …`, иначе полумесяцы на скруглении.
3. **Вложенные рамки.** Любой `div` с `border: 1px solid var(--color-divider)` внутри `.blueprint` → `border:0;
   background:var(--color-bg); border-radius:10px`. Сейчас это даёт двойные рамки (главная «Внутренний подбор»,
   вход «Найдено по ИНН», KPI админки).
4. **Фото-плиты вне `.blueprint`.** `.duotone[data-photo]`, `div.ph[data-photo]`, `figure` — всем `border-radius:var(--radius-lg)`
   и, если это самостоятельный блок, `box-shadow:var(--shadow-card)`. Контейнер баннеров кластеров на «Направлениях» — обязательно.
5. **Подложка packshot.** Для `.ph[style*="contain"]` задать фон одного тона со снимками (`#eef0f2`) через
   `background-color: … !important`, иначе полосы по бокам.
6. **Счётчики и бейджи.** `span.mono[style*="position: absolute"][style*="min-width: 16px"]` → круглые пилюли, обычный шрифт.
   Бейджи на фото карточек — пилюли.
7. **Моно-капс лейблы.** `.mono[style*="text-transform: uppercase"]` над заголовками: ослабить до `font-family:var(--font-body);
   letter-spacing:.04em; font-size:12px; color:var(--color-neutral-600)`, а в разметке оставить не больше одного на экран.
8. **Чипы/пилюли.** Все `a/span` с рамкой и `font-size:12–13px` в hero и фильтрах → `border-radius:999px`. На тёмном фоне —
   полупрозрачный белый фон, не рамка.
9. **Кнопки на тёмном фоне** (подвал, hero): `border-radius:8px`, рамка `rgba(255,255,255,.2)`, без моно-шрифта.
10. **Формы.** `label + .input` / группа поля — единый ритм `gap:6px`, между группами `16px`.
11. **Иконки — всё или ничего.** Внутри одной группы (список, ряд фактов, строки таблицы, табы) иконки у всех элементов
    и разные по смыслу; одинаковая иконка у всех табов — хуже, чем без иконок.
12. **Мобильные таблицы.** `@media (max-width:760px)`: `.table` → карточный режим либо `overflow-x:auto` + липкая первая колонка;
    скрыть верхнюю тёмную полосу; фильтры каталога и 45-пунктовый каталог на главной — свернуть.
13. **Липкие колонки.** Правые колонки товара и статьи (`aside` с ценой/позициями) — `position:sticky; top:96px` на ≥1024px.
14. **Единая ширина контейнера** 1304 px на всех витринных страницах (сейчас заказ, поиск, вход, поиск по фото — 1044 px).
15. **Стрелки карусели и степперы** — круглые, 40 px; ленты карусели не вылезают за поля контейнера.
