# Китай против отгрузки из РФ — сводка (15.09.2026)

Источник — 8 отчётов агентов в этой папке (01–08). Цены FOB — с Alibaba/Made-in-China/сайтов заводов,
сентябрь 2026; экономия «до ввоза» и «после ввоза» разделена. Курс в расчётах агентов — 84,34 ₽/$.

## Главные выводы

1. **Напрямую не купить.** Alibaba.com с 05.2024 не доставляет в РФ и не берёт рубли, 1688 — только через
   посредника с юрлицом в Китае. Рабочая схема: байер/ВЭД-агент (3–5 %) + платёжный агент (1,5–5 %).
2. **Только «белая» схема.** Карго бьёт по покупателю (ст. 16.21 КоАП, 50–200 % стоимости с конфискацией),
   нет ГТД и вычета НДС — для B2B-площадки недопустимо.
3. **Китай выгоден только консолидированно.** Одиночный насос 15 кг ($300 FOB) авиа «в одиночку» выходит
   ~72,7 тыс. ₽ без наценки — брокер 20 тыс. ₽ и логистика съедают всё. Значит на сайте «Китай» = сборная
   отправка по расписанию (раз в 2–4 недели), брокер и сертификация делятся на партию.
4. **Много китайских заводов уже имеют склад в РФ** (Kaishan, CNP, Supror, Guomao, Boneng, Dazhong, Kinco,
   Opple, ZWZ, Tolsen, Sinopec, Bodor, Jasic=«Сварог», Riland=«КЕДР»). У них оба варианта сразу:
   «склад РФ» и «под заказ с завода» — это самый быстрый старт функции.

## Цена «под ключ» — формула вместо плоских 12 % / 25 % в админке

```
Себестоимость на складе в Москве =
  FOB × курс ЦБ × (1 + комиссия платёжного агента 1,5–5 %)
+ логистика: вес × ставка способа (ж/д/авто сборный $1,5–3,3/кг; контейнер 40HC $5 500–9 500 делится по м³)
+ пошлина = (FOB×курс + логистика) × ставка кода ТН ВЭД (8413 — 0 %, 8414 — 0 %, 8501 — 0/5/11 %,
            8483 — 10 %, 8481 — 15 %, 8482 — +31,3–41,5 % антидемпинг)
+ доля партии: таможенный сбор (1 231–73 860 ₽) + брокер (20–28 тыс. ₽) + декларация ТР ТС 010 (8–19,5 тыс. ₽)
+ услуги байера/ВЭД-агента 3–5 %
+ НДС 22 % на (таможенная стоимость + пошлина) — кассовый разрыв, клиент на ОСН берёт к вычету
Цена на сайте = себестоимость × (1 + наценка) + доставка по РФ
```

Срок «от заказа до склада в Москве»: производство 7–30 дн. + ж/д/авто 18–35 дн. + таможня 1–5 дн.
→ показывать диапазоном **35–70 дней**, для «Ready to ship» у заводов с остатком — 25–45.

## Схема работы (рекомендация агентов)

- Для клиента — **договор поставки с ПРОМКОНТУР**: один продавец, одна гарантия, неустойка за просрочку.
- Ввоз — **агентский договор с ВЭД-партнёром** (он декларант, ГТД, EAC).
- Предоплата **30/70**: 30 % на запуск производства, 70 % после отгрузки с завода и инспекции.
  Курс юаня фиксировать в договоре на момент оплаты. Для крупных первых сделок — аккредитив.
- Риск сроков реален: срывы у 44 % импортёров в 2025 (1 источник) — закладывать запас и компенсацию.
