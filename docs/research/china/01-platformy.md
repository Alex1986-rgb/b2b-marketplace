# Китайские B2B-платформы как источник товара и цен для ПРОМКОНТУРа

Дата разведки: 15.09.2026. Метод: Exa web search + fetch, без Firecrawl (нет кредитов), без регистраций и покупок.
Пометки достоверности: **[2 источника]** — подтверждено минимум двумя независимыми страницами; **[1 источник]** — единственный источник, трактовать как ориентир; **(оценка)** — расчётная/экспертная оценка без первичных данных; `—` — не найдено.

## 2. Верификация поставщика: как отличить завод от перекупщика

По данным Alibaba.com (seller.alibaba.com blog, 2026-04-02) и axencis.com (2025-08-22):

| Признак | Завод | Трейдер/перекупщик |
|---|---|---|
| Badge на Alibaba.com | Gold Supplier (стаж, годы "4YRS" и т.п.) + Verified Supplier + Assessed Supplier (видео, фото цеха, отчёты об инспекции) | Часто без онсайт-аудита, "Multispecialty Supplier" |
| Онсайт-аудит третьей стороной | SGS, TÜV Rheinland, Bureau Veritas — со ссылкой на конкретную дату проверки (пример: "Verified onsite by TÜV Rheinland, 2026.01.07") | Отсутствует или устарел |
| На 1688.com | "Delivery Guarantee" бейдж (депозит на платформе), стаж >3 года, штат >50 человек, размер офиса/цеха | Штат <50 человек часто = трейдинговая компания, а не завод **[1 источник: axencis.com]** |
| На Made-in-China.com | Премиум-поставщики с аудитом SGS/BV | Обычные поставщики без доп. верификации |

Практический чек-лист для закупщика (свод из нескольких источников): смотреть сертификаты ISO/CE с проверяемыми номерами, историю сделок (transaction history) и отзывы именно про решение спорных случаев, штат/размер цеха, требовать видео цеха и образец перед крупным заказом.

## 3. Программный доступ к ценам и каталогам (API)

### 3.1 Официальные API

| Источник | Что это | Легальность/стоимость | Что отдаёт |
|---|---|---|---|
| **Alibaba Open Platform (Taobao/TOP shared gateway)** | Открытый API Alibaba.com для управления товарами/заказами (интеграция ERP↔маркетплейс), >20 методов | Бета была бесплатна для платных GGS-пользователей; лимиты по вызовам, превышение → предложение платной подписки, иначе — блокировка аккаунта **[1 источник: developer.alibaba.com]** | Товарные данные, заказы, но именно "поиск по всему рынку цен конкурентов" не для этого сделан — это API для *своего* листинга/учёта, не для стороннего парсинга чужих цен |
| **1688 Open Platform (open.1688.com)** | Официальный открытый API 1688: `alibaba.product.list.get`, `alibaba.offer.search`, `alibaba.item.get`, заказы, логистика, категории | **Базовые методы бесплатны** (товар/заказ/логистика), лимит QPS 10-20/сек по умолчанию; платные "resource packs" ¥980–2980/год за повышение QPS и премиум-фичи (реалтайм-остатки, кросс-бордер insights, push-уведомления, дропшип-функции) **[2 источника: alexob.com 2026, jsqmd.com 2026-09-05]** | Цена (обычная + ступенчатая по объёму — ladder price), MOQ, остаток (базовый snapshot бесплатно, реалтайм с блокировкой — платно), вес, категория, изображения, продавец. Официально требует регистрации через китайское юрлицо/аккаунт разработчика на 1688 — доступ иностранцу напрямую затруднён (нужен app_key/app_secret, авторизация продавца) |
| **Taobao/Tmall Open Platform (alitrip)** | Аналогичный протокол (та же инфраструктура TOP), в т.ч. `alibaba.dropshipping.product.get` — данные для дропшиппинг-партнёров (цена, ladder price, MOQ, сток по складам) | Похоже на 1688 API по модели: часть бесплатно, лимиты по вызовам | Полные карточки: описание, цена по диапазонам, MOQ, сток по складам, изображения, SKU/вариации |

**Вывод:** официальные API 1688/Alibaba рассчитаны на **своих продавцов и их ERP**, а не на построение стороннего ценового агрегатора по чужому каталогу. Для полноценного фида "весь рынок по категории редукторов" официальный путь не даёт прямого доступа без роли продавца/дистрибьютора на этой платформе.

### 3.2 Посредники-агрегаторы API (для стороннего парсинга чужих карточек)

| Сервис | Модель | Стоимость (по открытым данным) | Покрытие |
|---|---|---|---|
| **Onebound (万邦)** | Китайский агрегатор, оборачивает Taobao/1688/JD/Amazon/AliExpress/eBay в единый REST API (`item_get`, `item_search`, `item_search_img` — поиск по фото, `seller_info` и др.) | Годовые тарифные пакеты, например 1688 — от ¥5000/год за пакет + отдельная "annual API fee" ¥5000–50000 в зависимости от пакета (по прайс-таблице onebound.net) **[1 источник]** | 1688, Taobao/Tmall, JD, Amazon, AliExpress, eBay и др. |
| **OTAPI / Opentrade Commerce (otcommerce.com)** | REST API + плагины для OpenCart/WooCommerce/Magento/Shopify, интеграция каталогов Taobao/1688/Alibaba/AliExpress/JD/Amazon/eBay/Shein/Trendyol/Poizon | Тарифные планы K0 Basic $150, K1 Standard $300, K2 Light — pay-per-call без фикс. платы, K3 Enterprise — от $400-600 **[1 источник: otcommerce.com]** | Тот же список маркетплейсов, включая перевод и конвертацию валют "из коробки" |
| **TMAPI** | Специализированный API для Taobao/1688/Amazon/Shopee и др., методы item-detail (по URL), search по ключевым словам с фильтрами (MOQ, цена, дропшиппинг, "super factory") | Не найдена открытая цена, вероятно платная подписка `—` | 1688, Taobao и др. |
| **ReefAPI** | Специализированный API конкретно под Alibaba.com Wholesale (search, product_detail, rfq_search) | 1000 бесплатных кредитов без карты, далее платно **[1 источник: reefapi.com]** | Только Alibaba.com — отдаёт price_ladder (ступенчатая цена), MOQ+unit, вес/габариты упаковки, вариации SKU, сертификаты, скоринг поставщика, страну |
| **Apify-акторы** | В этом заходе целевого поиска не делал — по общей практике на Apify есть готовые скрейперы Alibaba/1688 под pay-per-result модель | — | — (нужен отдельный проход, см. "что осталось") |

**Легальность:** это парсинг/реверс-инжиниринг чужого сайта через посредника, а не официальный контракт с Alibaba Group — юридический статус спорный (нарушение ToS платформы возможно), но de facto существует целая индустрия таких сервисов (Onebound, OTAPI и др. работают открыто много лет). Для ПРОМКОНТУРа это риск на стороне поставщика данных, не конечного покупателя фида.

**Можно ли строить автофид в каталог:** технически да — через ReefAPI/Onebound/OTAPI можно вытягивать price_ladder, MOQ, фото, характеристики и обновлять карточки в каталоге ПРОМКОНТУРа автоматически. Практическое ограничение: поля стандартизированы слабо (единицы MOQ не нормализованы — "meters"/"pieces"/"sets" в одном списке), нужен слой нормализации на своей стороне.

| Сервис | Комиссия выкупа | Модель проверки | Оплата от клиента | Особенности |

**Общая механика (устойчиво повторяется у всех):** клиент → ссылка на товар/спецификация → посредник считает смету в рублях → клиент платит рублями на счёт российского/подставного юрлица посредника → посредник (имея юрлицо и банковский счёт в КНР, обычно в Гуанчжоу) платит юанями через Alipay Business/Chouzhou Commercial Bank/собственные "проверенные каналы" → приёмка на складе в Гуанчжоу с фото/осмотром → консолидация → доставка в РФ (авто 12-18 дней, авиа 11-13, экспресс 1-4, ЖД 22-35 — по china911.ru).

**Диапазон комиссий по рынку: 3-5% от стоимости товара** (устойчиво у всех, кто называет цифру), отдельно логистика и таможня.

## 5. Риски

### 5.1 Контрафакт брендов
- На **1688.com IP-защита формально слабее**, чем на Alibaba.com — платформа изначально не проектировалась для международной торговли и защиты брендов **[1 источник: axencis.com, 2025-08-22]**.
- По оценке OECD (со ссылкой в русскоязычном источнике), **75% конфискованных подделок в мире происходят из Китая**, касается и промоборудования, не только потребительских товаров **[1 источник: oborudovanie-iz-kitaya.com]**.
- Про подшипники **SKF**: по независимым оценкам до **30% всех "SKF" на российском рынке — контрафакт**, в мелкооптовом сегменте через неавторизованные онлайн-площадки — до **50-70%** **[1 источник: motion-tech.ru]** — оценка от конкурента-дистрибьютора, воспринимать как верхнюю границу, но направление показательное.
- Про насосы **Grundfos**: задокументированы случаи подделок именно китайского производства (маркировка страны "GB" на подделке при реальном производстве в КНР), кейс завода в Ростове-на-Дону — 40% "экономии" при закупке обернулась штрафом 1 млн руб от Ростехнадзора и убытками от простоев **[1 источник, иллюстративный кейс без первички]**.
- Способы проверки на площадке: дата производства на шильдике (у подделок часто "заморожена" на много лет), сверка серийного номера через официальный сервис производителя (у Grundfos — product-selection.grundfos.com), вес/размеры не совпадают с оригиналом, орфографические ошибки в бренде.

### 5.2 Платежи и санкции (ключевой риск для схемы ПРОМКОНТУРа)
- Alibaba.com с мая 2024 г. **не принимает рубли и не оформляет доставку в РФ** напрямую, кроме банков Беларуси/Центральной Азии **[2 источника: cnews.ru, rbc.ru 2026-04-20]**.
- Крупные госбанки КНР — **Bank of China, ICBC, China Construction Bank** — ужесточили комплаенс к платежам из РФ из-за угрозы вторичных санкций США; часть переводов отклоняется без объяснений, требуют полный пакет документов (контракт, инвойс, подтверждение происхождения товара, логистика) **[3+ источников: rbc.ru, vc.ru×3, expert.ru]**.
- Оценки успешности прямых SWIFT-платежей в крупные китайские банки из РФ: **20-40%** (vc.ru, апрель 2026) или Т-Банк оценивает отказ **7-8 из 10 переводов** (grantec-m.ru, март 2026) — оценки расходятся, но направление единое: прямой платёж — лотерея.
- Работающая альтернатива: **юаневые платежи через CIPS и региональные/приграничные банки** (Heihe Rural Commercial Bank, Harbin Bank и др., не через доллар) — успешность оценивается в **60-85%** в разных источниках vc.ru (март-май 2026), но это не гарантия, а иллюстрация принципа "маленькие региональные банки надёжнее крупных госбанков".
- Апрель 2026: Госсовет КНР закрепил правило о недопустимости исполнения "необоснованных" иностранных санкций китайским бизнесом — юридическая защита появилась, но de facto банки продолжают действовать по принципу самосохранения от вторичных санкций США **[1 источник: rbc.ru, 2026-04-15]**.
- **Практический вывод для схемы закупки:** прямой платёж российского юрлица ПРОМКОНТУРа в китайский банк — рискованная схема с непредсказуемым исходом; отраслевой стандарт — платить рублями посреднику с юрлицом в КНР (карго-компания), тот платит юанями по своим "проверенным каналам" (описано в разделе 4).

## 6. Рекомендация для ПРОМКОНТУРа

**Для ценового ориентира (что показывать покупателю "цена из Китая ~от X"):**
- Alibaba.com search/product_detail через сторонний API-агрегатор (ReefAPI — есть бесплатный старт 1000 кредитов на тест, или Onebound/OTAPI для более широкого покрытия) — это единственный сегмент, где цена сразу в USD, ступенчатая по объёму, с MOQ и сертификатами поставщика.
- 1688 держать как "теневой" источник самой низкой цены (обычно на 20-40% ниже Alibaba, по оценке одного посредника) для внутреннего расчёта маржи, но **не показывать напрямую конечному клиенту** как "цену закупки" без наценки на выкуп+логистику+риск.

**Для реальной закупки партии:**
- Не пытаться платить в Китай напрямую с российского юрлица — риск заморозки/возврата платежа слишком высок (оценки 20-40% успешности через крупные банки). Работать через посредника-байера с юрлицом в КНР (china911, 611cargo, AGB Global и аналоги) — комиссия 3-5% от суммы товара плюс логистика/таможня отдельно.
- Для промышленного оборудования (не мелкий опт) — обязательна физическая инспекция перед оплатой поставщику: либо через посредника с выездом сотрудника на фабрику (модель AGB Global — оплата только после осмотра), либо через SGS/TÜV инспекцию для заказов от условных $5000-50000 (по рекомендации Alibaba.com для крупных сделок).
- Приоритет — заводы с онсайт-аудитом (Verified Supplier + отчёт SGS/TÜV с датой) над трейдерами без верификации, особенно для брендированных компонентов (подшипники, насосы) — там риск подмены оригинала на контрафакт из Китая максимален.

**Для автоматического фида в каталог:**
- Технически реализуемо через ReefAPI (для Alibaba.com) или Onebound/OTAPI (для более широкого покрытия 1688/Taobao/JD), но:
  - юридический статус парсинга через посредника — серая зона (не официальный контракт с Alibaba Group);
  - поля MOQ/единицы измерения не нормализованы между листингами — нужен слой очистки на своей стороне;
  - для 1688 полноценный офишиал-доступ фактически требует роли продавца/дистрибьютора на самой платформе, что для ПРОМКОНТУРа избыточно.
- Практичная схема: начать с ручной/полуавтоматической сверки топ-категорий (насосы, редукторы, подшипники) через один платный API-агрегатор с пробным периодом, оценить качество и стабильность полей 2-4 недели, потом решать про масштабирование.

**Итоговая связка "две скорости" для сайта:**
1. **"Из Китая под заказ"** — цена = ориентир с Alibaba.com/1688 (через API или ручной мониторинг) + наценка на выкуп (3-5%) + логистику + таможню + маржу ПРОМКОНТУРа + срок 25-45 дней (по срокам логистики карго-компаний: авто 12-18 дн., авиа 11-13 дн., ЖД 22-35 дн., плюс сбор партии и оформление).
2. **"Склад РФ"** — быстрая отгрузка, цена выше, риск контрафакта и платёжный риск — на стороне склада/поставщика РФ, не на ПРОМКОНТУРе.
