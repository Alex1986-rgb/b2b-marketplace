Это отдельная задача — прогнать эталон через ApiShip или напрямую через ПЭК/СДЭК калькуляторы.

## 2. Отсрочка платежа для B2B-покупателей (BNPL / факторинг)

Ключевое разграничение: **факторинг для поставщика** (площадка/банк финансирует поставщика под уступку требования к покупателю с отсрочкой) vs **B2B BNPL для покупателя** (покупатель платит частями, площадка получает деньги сразу). Для модели ПРОМКОНТУРа («покупателю — отсрочка до 30 дней», площадка не хочет кредитного риска) нужен именно **закупочный/реверсивный факторинг** или встроенный BNPL-провайдер, который берёт риск покупателя на себя.

## 3. Счёт за 15 минут и ЭДО

### 3.1 Проверка контрагента по ИНН

## 4. Итог: минимальный технический стек для запуска сделок

| Функция | Рекомендация | Ориентировочная цена/мес (или разово) | Порядок подключения |
|---|---|---|---|
| Расчёт доставки (агрегатор нескольких ТК) | **ApiShip** (POST `/calculator` по нескольким перевозчикам одним запросом) | Цена подписки не найдена в открытых источниках — нужен запрос в отдел продаж; типично для таких агрегаторов — от нескольких тысяч ₽/мес + комиссия за заказ | Регистрация → создание `/connections` под ИНН площадки/поставщиков → тест-запросы в песочнице `dev.apiship.ru` → прод-ключ |
| Прямые договоры с 1–2 ключевыми перевозчиками (для собственных ставок/скидок) | ПЭК или СДЭК (крупная сеть филиалов, готовый API, скидки по договору до 40%) | Интеграция бесплатна; тариф — по факту перевозок | Заявка юрлица → договор (оферта/индивидуальный) → API-ключ из личного кабинета |
| Проверка контрагента по ИНН | **DaData** «Лёгкий» | 14 000 ₽/год (≈1 170 ₽/мес) | Регистрация на dadata.ru → API-ключ → интеграция в форму регистрации покупателя/поставщика |
| ЭДО с контрагентами | **СБИС** или **Диадок** — любой из двух, выбор по совместимости с будущими крупными поставщиками (уточнить, у кого они уже подключены, за счёт роуминга) | От ~2 000–3 000 ₽/год на 200 документов при низком старте, далее по объёму (см. таблицу 3.2) | Регистрация оператора → покупка тарифа «Обмен с контрагентами» / пакета документов → API-ключ или Коннектор → интеграция в бэкенд выставления счетов |
| Отсрочка платежа для покупателя без риска площадки | **Закупочный/реверсивный факторинг** — Альфа-Банк «Факторинг для покупателей» (от 8,5% годовых, акция) или Т-Банк аналог | Ставка ложится на покупателя (или комиссию делят по договору с поставщиком) — не является прямым расходом площадки, но требует юридической встройки в чек-аут | Переговоры с банком-фактором → интеграция заявки покупателя на факторинг в оформление заказа → подписание рамочного соглашения между площадкой/банком |
| Приём онлайн-оплаты юрлицом | СБП B2B через расчётный банк площадки (низкая комиссия, лимит 1 млн ₽/операция) + эквайринг как резерв для крупных сумм | Комиссия по СБП — индивидуально у банка; эквайринг — от ~1% | Подключение СБП для приёма платежей у расчётного банка → эквайринг у того же банка как fallback |

### Порядок запуска (сжато)
1. Открыть расчётный счёт с поддержкой СБП B2B и эквайринга (действующий банк площадки).
2. Подключить DaData (проверка ИНН при регистрации покупателя/поставщика) — быстрее и дешевле остальных вариантов.
3. Подключить ЭДО-оператора (СБИС или Диадок) — для автоматической генерации и обмена счетами/накладными.
4. Подключить ApiShip или напрямую 1–2 крупных перевозчика (ПЭК/СДЭК) — для расчёта доставки в чек-ауте.
5. Договориться с банком-фактором (Альфа-Банк/Т-Банк) о закупочном факторинге для покупателей — отдельный юридический трек, не блокирует запуск MVP.

### Что не подтверждено и требует отдельной проверки
- Точный тариф перевозки на эталон (100 кг/0,5 м³ Москва→Екатеринбург, Москва→Тула) — не получен ни по одному перевозчику без live-вызова калькулятора с реальными кодами городов.
- Условия Норвик Банка, ГПБ-факторинга, Factorin, Калуги Астрал — не найдены за отведённое время, нужен точечный повторный поиск.
- Актуальная стоимость подписки ApiShip (сайт не публикует тарифы открыто).
- Т-Банк «Отсрочка для бизнеса» как отдельный публичный тарифный лист (найден только общий факторинговый продукт без фиксированной базовой ставки).
