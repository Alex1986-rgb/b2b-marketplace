# Механика сайта ПРОМКОНТУР (разбор 15.09.2026)

## Как устроен
- **Статика без бэкенда.** Макет Claude Design (`project/Промышленный агрегатор.dc.html`, React-документ на 38 экранов)
  рендерится puppeteer-ом в `site/` (`tools/build_site.js` + `routes.js`). 24 товара, 44 направления, 15 брендов,
  16 статей генерируются из `tools/data/*.json` (`gen_pages.js`). Публикация — GitHub Pages.
- **Всё состояние — localStorage** (`pk:cart2`, сравнение, сессия роли). Сетевых запросов нет, формы — демо «принято».
- **Роли** (`auth.js`): закупщик (кабинет), поставщик (кабинет поставщика), оператор (панель). Вход — демо по телефону.

## Путь покупателя
Главная → направление → каталог (фильтры по типу/подаче/напору/наличию, `?tip=`) → карточка
(цена с НДС и доставкой, остаток «8 шт.», срок «Отгрузка 2–4 дня», гарантия, аналоги) → корзина
(пересчёт, НДС 22 %) → счёт / отсрочка до 30 дней → кабинет (заказы, статус, КП, автозакупка).
Альтернативные входы: поиск (опечатки, транслит, артикул), фото шильдика, чат-подбор, заявка Excel списком,
«под проект» (КП за 2 часа, пример — Kaishan LGCY-75), сравнение оригинал/аналоги по цене и сроку.

## Модель бизнеса (из макета)
«Не склад и не магазин, а контур закупки»: поставщики РФ подключают прайс (Excel / XML-YML / REST API-1С,
расчёт 7/5/3 дня), заказ уходит поставщику, отгрузка напрямую клиенту, ПРОМКОНТУР берёт наценку
(пример: закупка CR 32-4 86 000 → витрина 104 900, ~22 %). Робот торгуется в рамках: скидка ≤ 6 %, маржа ≥ 9 %.

## Что уже есть под Китай
- Панель `panel/admin`: таблица направлений с колонками «Поставщики РФ» / «Китай / импорт»; тип источника
  Alibaba.com / 1688.com / Made-in-China / прямой завод; форма «Импорт из Китая: расчёт цены»
  (курс ЦБ+2 %, логистика 12 % от FOB, пошлина и НДС 25 %, наценка 20 %).
- **На витрине Китая нет.** У товара одно предложение: одна цена, один остаток, один срок.
  Сравнение показывает аналоги, но не варианты поставки одной позиции.

## Разрыв под задачу «Китай — подождать / наша отгрузка»
1. Модель данных: у товара нужен массив предложений `offers[]` {источник: РФ-склад | Китай под заказ,
   цена, срок, предоплата, MOQ, гарантия, документы}.
2. Карточка и каталог: переключатель варианта, «от N ₽ из Китая за X–Y дней», фильтр по сроку.
3. Корзина и заказ: разделение на партии с разными сроками, предоплата для Китая, статусы в пути
   (завод → граница → таможня → склад РФ).
4. Калькулятор в админке: пошлина по ТН ВЭД, НДС 22 %, реальная логистика $/кг или % — вместо плоских 12/25 %.
5. Юридически: кто импортёр, сертификаты ЕАЭС, гарантия, возвраты — должно быть видно покупателю.
